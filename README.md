## 写文章

在 `_posts/` 下新建 `YYYY-MM-DD-slug.md`：

```markdown
---
layout: post
title: "文章标题"
date: 2026-01-01
categories: ai
tags: [AI, Agent]
original: https://www.yuque.com/...
---

正文（Markdown）
```

分类：`ai`（AI/智能体）、`iot`（车联网）、`bigdata`（大数据）。
