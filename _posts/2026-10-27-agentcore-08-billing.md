## 一、计费开通

| 项 | 说明 |
| --- | --- |
| 计费启动 | **2026-09-18 00:00:00（GMT+8）**起开启计费服务 |
| 开通方式 | 控制台「立即开通」→ 确认计费方式与协议 → 服务关联角色授权与依赖产品开通；开通本身**免费**，资产原样可用 |
| 子账号 | 可能提示权限不足，需主账号管理员授权 |

## 二、计费项总览（按量付费）

月费 = 算力 CU + 网关 CU + 存储 CU + 协作专享管控面（可选）+ 公网流量。

| 类别 | 计费项 | 计量维度 | 参考单价（上海） |
| --- | --- | --- | --- |
| 构建与运行 | 算力 CU | vCPU 与内存用量换算 | 0.0000694 元/CU |
| 构建与运行 | 网关 CU | 请求调用次数 | 0.0000015 元/CU |
| 构建与运行 | 存储 CU | GB/小时 | 0.00025 元/CU |
| 协作管控面 | 协作专享管控面 | 实例/小时 | 3 元/小时 |
| 公网流量 | 公网流量 | GB（CDT 统一出账） | 0.8 元/GB |

<div class="callout callout-note" markdown="1">
**📝 上表只含 AgentCore 自身资源**

一并开通的其他阿里云产品按各自规则独立计费（如 SchedulerX3 购买、云监控）；**模型 Token 费用走模型供应商账单**（如百炼），不在上表内。
</div>

### 1. 算力 CU 换算

| 用量 | CU |
| --- | --- |
| 1 vCPU × 1 秒 | 1 CU |
| 1 GB 内存 × 1 秒 | 0.5 CU |

计费示例：1C2G 持续跑 1 小时 = 3600 + 3600 = 7200 CU ≈ **0.4997 元/小时**（≈ 0.5 元/CPU核时，单算 1 vCPU 或 2GB 内存各约 0.25 元/小时）。

### 2. 网关 CU

- 1 次请求调用 = 1 网关 CU
- 长连接（流式响应、MCP 长连接、Agent 长会话）按保持时长**每 30 秒折算 1 次**
- 请求体/响应体数据量按「数据处理量」单独计费（不影响次数）

### 3. 存储 CU

1 存储 CU = 1 GB 用 1 小时；10 GB 存一个月（720h）≈ **1.8 元**。

### 4. 地域单价差异

| 地域 | 算力 CU | 网关 CU | 存储 CU | 管控面/小时 |
| --- | --- | --- | --- | --- |
| 北京/杭州/上海/深圳 | 0.0000694 | 0.0000015 | 0.00025 | 3 元 |
| 新加坡 | 0.0001 | 0.0000015 | 0.00028 | 4 元 |
| 中国香港 | 0.0001 | 0.0000015 | 0.00028 | 4.5 元 |

### 5. 协作管控面限免活动

- 2026-09-18 ~ 2026-10-18 23:59:59 全账号协作管控面**限时免费**（原价 3 元/小时；账单正常推但金额 0 元）
- 限免期实例**连续 30 天无操作会被停用并回收**（不可逆，协作数据找不回）；30 天内用一次协作功能即重置计时
- 活动结束后计费策略另行通知

## 三、使用约束与坑位清单（全量整理）

<div class="callout callout-warning" markdown="1">
**⚠️ 托管 Harness 当前「暂不支持」项**

- 知识库（配置页暂不支持挂载，知识库连接先用于高代码/其他形态）
- 长期记忆（记忆空间需 MCP/SDK 方式接入引导）
- 环境变量
- 工具审批与人工交互
- 调整模型参数（QwenPaw/Qoder 都不支持）
</div>

### 资源与运行

| 约束 | 说明 |
| --- | --- |
| OSS 挂载上限 | 最多 **10 个**挂载点；路径限 `/mnt/oss/` 下且同 Agent 内不重复 |
| Session 并发模型 | 同一 Session 串行排队；不同 Session 并发；实例到顶后新 Session 报容量不足 |
| Session 数 ≠ 算力 | 同实例 Session 共享 CPU/内存，调大上限不加资源 |
| Session TTL | 只管空闲回收，不控制单次生成耗时；TTL 长占用容量久 |
| 备份丢失窗口 | 异常中断时**最近 5 秒**未备份内容可能丢失 |
| 工作文件不备份 | 持久化必须走 OSS 挂载 |
| 热更新边界 | 模型/提示词/Skill/Subagent/MCP/凭证热更新；规格/镜像/挂载点需重启（建议任务结束后改） |
| 扩缩容 | 关闭自动扩缩容后不会自动加实例；新实例有启动时间 |

### Skill

| 约束 | 说明 |
| --- | --- |
| 发布需审核 | 开通 AI 安全护栏后走审核（审核未通过可强制发布，风险自担）；未开通可直接发布 |
| 自定义别名未开放 | 多环境/灰度暂用 latest 或具体版本号 |
| 生产禁用 HEAD | 工作区版本保存即生效，生产引用 latest 或版本号 |
| 版本不可变 | 正式版本创建后不能改，只能发新版本 |

### 知识库与 MCP

| 约束 | 说明 |
| --- | --- |
| 一连接一库 | 多知识库分别建连接 |
| 模板参数定死 | 换实例/业务空间/知识库 = 删连接重建 |
| 自由编辑单向 | 模板托管 → 自由编辑不可逆 |
| MCP 网络可达 | URL 必须网络可达；描述 ≤ 1000 字符 |
| 只读检索 | AgentCore 不管文档上传/切片/索引，去原产品控制台维护 |

### 网络与安全

| 约束 | 说明 |
| --- | --- |
| 交换机 IP 余量 | 开通**协作私网接入**时每个交换机可用 IP ≥ 31（不可合并计数，仅创建前校验）；Workspace 绑定 VPC 亦会占用交换机 IP |
| 双网络独立 | Workspace 网络（Agent 访问资源）与协作网络（客户端连协作服务）分开保存、互不同步 |
| 公网出口 | Workspace 公网出口 IP 仅用于出站白名单，**不能作为调用地址** |
| API Key 位置 | 只存应用服务端，禁止进前端 |
| 凭证管理 | Key-Value 集中管理，最小权限、定期轮换 |

### 纳管与协作

| 约束 | 说明 |
| --- | --- |
| 纳管 Agent 角色 | 只能 Team Worker，不能 Leader；仅可加入一个 Team；前提是已开 Team 协作 |
| 本地运行时 | 必须装 Claude Code / Codex / OpenClaw / Qoder CLI 之一 |
| 定时任务 | 依赖 SchedulerX（需购买） |
| 管控面回收 | 限免期 30 天无操作停用回收，不可逆 |

### 账号与地域

| 约束 | 说明 |
| --- | --- |
| 地域 | 杭州/上海/深圳/北京/新加坡；香港仅在计费表出现，地域列表未列（开通前确认） |
| 计费开通 | 2026-09-18 后需手动开通；长期不开会释放公测 Workspace |
